# Portfolio

A React portfolio starter powered by Vite, Tailwind CSS, React Icons, and Animate.css.

## Requirements

- Node.js 20.19+ or 22.12+

## Run locally

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

## Included libraries

- React
- Tailwind CSS (using the official Vite plugin)
- React Icons
- Animate.css
